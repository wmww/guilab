# Human messages lack some of the context they refer to

Short messages ("also that black color") need to know what the human was looking at. Built: a message without images carries `screen` (the session with the pointer drawn in, captured as the human started typing it), and any message names a past image open in their editor (`viewing`); `poll` points the agent at both.

Still open, if agents keep misreading short messages: other viewer context (the selected tool, the current tab).
